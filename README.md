# ManiaTip

ManiaTip modifies the World of Warcraft tooltip.

## Features
- Names, borders and health bars colored by class or reaction
- Item tooltip borders colored by quality
- Change the reaction and guild colors
- Show AFK, DND and offline tags as text, icon or tab
- Show the class text in class color
- Show the target of the unit
- Show player titles
- Show player realms
- Show names in Latin letters
- Show item and spell IDs
- Hide the PvP line
- Hide the faction line
- Hide the right-click hint on unit frames
- Change the tooltip border style
- Change the tooltip background and border colors
- Change the tooltip scale
- Change the tooltip font, size, outline, shadow and smoothing
- Change the health bar texture
- Hide the health bar
